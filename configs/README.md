# Case configurations

This folder records the case-level settings that accompany the examples.

- `yen.yaml`: Yen scenario files and train/validation/test split
- `bump.yaml`: Bump scenario table and split
- `waiho_template.yaml`: path template for applying the workflow to the Waiho case

Model hyperparameters are kept with the trained checkpoint rather than duplicated here unless a run has been verified as the manuscript version.
