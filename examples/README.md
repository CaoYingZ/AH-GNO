# Examples

The repository includes two public TELEMAC-MASCARET/GAIA benchmark setups and notes for the Waiho field case.

- `yen/`: 20 forcing hydrographs and the scenario split
- `bump/`: 8 discharge/water-level combinations and the scenario split
- `waiho/`: field-case notes; restricted geometry and bathymetry are not included

The benchmark folders contain the study-specific inputs needed on top of the corresponding TELEMAC examples, not copies of the full TELEMAC distribution.
