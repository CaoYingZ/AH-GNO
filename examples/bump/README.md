# Bump

The Bump case is based on the standard TELEMAC-MASCARET/GAIA benchmark. Eight combinations of upstream discharge and downstream water level were used.

| Scenario | Upstream Q (m³/s) | Downstream level (m) | Split |
|---|---:|---:|---|
| B01_Base | 1000 | 10.0 | Train |
| B02_LowQ | 850 | 10.0 | Train |
| B03_HighQ | 1150 | 10.0 | Train |
| B04_LowZ | 1000 | 9.6 | Train |
| B05_HighZ | 1000 | 10.4 | Train |
| B06_LowQ_LowZ | 850 | 9.6 | Validation |
| B07_HighQ_HighZ | 1150 | 10.4 | Train |
| B08_HighQ_LowZ | 1150 | 9.6 | Test |

The full benchmark files remain in the TELEMAC installation. Only the scenario definition used in this study is recorded here.
